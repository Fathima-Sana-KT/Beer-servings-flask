One-time setup required

The dataset and trained model files are not available yet.

  1. Download drinks.csv.
  2. Save it beside app.py.
  3. Install dependencies with pip install -r requirements.txt.
  4. Run python train_model.py to tune and evaluate the models.
  5. Restart the app using python app.py.

The application will display the real evaluation scores after training. No scores are hard-coded.
