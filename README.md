# Beer Servings — Flask Regression Assignment

A Flask web application that predicts `total_litres_of_pure_alcohol` from:
- Country (categorical)
- Beer servings
- Spirit servings
- Wine servings
- Continent (categorical)

It compares Random Forest, Gradient Boosting, and Extra Trees regressors. GridSearchCV tunes each model using 5-fold cross-validation. The final model is selected by the highest held-out evaluation R² score and saved with evaluation metrics.

## 1. Dataset and model setup

The app and training script automatically download `drinks.csv` from the public dataset source if it is missing. On first app startup, the app trains and saves the models if `best_model.joblib` and `model_metrics.json` are missing. Hosting must allow outbound access to GitHub and allow writing files to the app directory.
The dataset is the FiveThirtyEight alcohol-consumption dataset. Its original columns include `country`, `beer_servings`, `spirit_servings`, `wine_servings`, `total_litres_of_pure_alcohol`, and `continent`.

## 2. Setup on macOS

Open Terminal and move into this project folder:

```bash
cd beer_servings_flask_assignment
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If you already have the dataset in the folder, training uses it; otherwise the script downloads it automatically. Train and compare the models:

```bash
python train_model.py
```

This generates `best_model.joblib` and `model_metrics.json`. Read the printed evaluation R² scores and selected model; do not invent or manually fill in scores.

## 3. Run the Flask app

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## 4. Files

- `app.py` — Flask routes, input validation, prediction, and landing-page charts.
- `train_model.py` — preprocessing pipeline, three regression models, hyperparameter tuning, evaluation, and model selection.
- `templates/index.html` — landing page with charts and prediction form.
- `templates/setup_required.html` — helpful message if the model has not been trained yet.
- `requirements.txt` — dependencies.
- `Procfile` — Gunicorn command for cloud hosting.
- `model_metrics.json` — generated evaluation results (created after training).
- `best_model.joblib` — generated best fitted pipeline (created after training).

## 5. Deploy

### Render (Flask-compatible alternative)
1. Push the project files to a GitHub repository. The service downloads the dataset and trains the models on first startup, so pre-generated model files are not required.
2. Create a new Web Service on Render and connect the repository.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn app:app`
5. Deploy and test the public URL.

The assignment suggests PythonAnywhere or Streamlit Cloud. Since this project uses Flask, PythonAnywhere is suitable; Streamlit Cloud is designed for Streamlit apps and is not the direct deployment choice for this Flask app. First-start model training can take a few minutes.

### PythonAnywhere
1. Create a PythonAnywhere account and upload/clone this repository.
2. Create a web app and select Flask / the Python version available for your account.
3. Install packages from `requirements.txt` in the web app's virtual environment.
4. Upload the trained model files and dataset, then configure the WSGI file to import `app` from this project's `app.py`.
5. Reload the web app and test the public URL.

## 7. Important notes for the report
- The target is predicted from the three serving counts plus country and continent.
- R² on the held-out evaluation split is the model-selection criterion.
- Cross-validation is used for hyperparameter tuning on the training split.
- The selected model and exact metrics are produced by `train_model.py`; report the actual values printed by your run.
- This is a small, historical country-level dataset. Its predictions are estimates and should not be interpreted as current individual consumption measurements.
